1. Set up the daily-brief-generation skill

The skill is part of the customer-success-toolkit plugin, so there is nothing to install separately.

In Claude, run:

/daily-brief-generation setup

Follow the prompts — it'll ask for your Drive folder ID and Slack user ID, then discover your customer accounts, Slack channels, and Asana projects automatically. Review and confirm what it finds.

When it finishes, it saves your configuration to Google Drive automatically — no manual edits needed.

2. Connect your data sources

The skill pulls from these — enable whichever apply to you under Claude's Settings → Connectors:

  • Microsoft 365 — Outlook calendar, email, availability
  • Slack — DMs, channel activity, mentions, posting status updates
  • Zoom — meeting summaries
  • Asana — task tracking
  • Google Drive — where your briefs, config, and status-update cache all live

Only connect what you actually use — the skill flags a source as "not found" rather than failing when one isn't hooked up.

3. A few other things

  • Claude Desktop, if you want the claude:// refresh and meeting-manager deep links in your briefs to work
  • See the skill repo's README.md for the full prerequisites list

4. Connect Asana (optional)

Adding your own Asana Personal Access Token lets this viewer pull your Overdue, Due Next 7 Days, and No Due Date tasks directly from Asana every time you load a brief — always current, not just whatever the skill saw on its last run. Only the New Items you saw above come from the brief run itself; this step is what turns on the other three.

To create one: sign in to Asana, go to your profile photo → My Settings → Apps → Personal Access Tokens → Create new token (or go directly to app.asana.com/0/developer-console). Give it a name like "Daily Brief Viewer" and copy the token — Asana only shows it once.

This is entirely optional. Skip it and finish setup — you can always add it later from the Account tab, and New Items will keep working either way.

Once your skill runs once, your brief shows up here automatically. Run /daily-brief-generation in Claude any time to generate one — you're all set.
